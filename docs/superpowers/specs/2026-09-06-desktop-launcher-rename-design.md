# 《单词消消养宠记》桌面启动入口彻底更名设计

## 目标

将 Windows 桌面快捷方式、项目启动脚本、用户说明和启动器测试中的旧名称“词灵星球”全部替换为“单词消消养宠记”，不保留旧快捷方式、旧脚本或兼容入口。

## 已确认根因

- 桌面仍存在 `词灵星球.lnk`。
- 该快捷方式指向主项目中的 `启动词灵星球.ps1`。
- 功能分支已完成游戏内更名，但 Windows 快捷方式不会随网页标题自动更名。
- 当前主项目仍停留在旧版本，新的养狗功能位于 `codex/dog-pet-home-dialogue` 专用分支。

## 方案

### 项目内启动器

- 将 `启动词灵星球.ps1` 直接重命名为 `启动单词消消养宠记.ps1`。
- 不创建旧文件名的包装脚本或兼容入口。
- 更新 README，只展示新的启动脚本名称。
- 更新启动器测试，使其显式定位 `启动单词消消养宠记.ps1`，并断言旧脚本不存在。
- 保持启动端口、健康检查、错误提示、隐藏后台进程和日志行为不变。

### 桌面快捷方式

- 删除桌面的 `词灵星球.lnk`。
- 创建 `单词消消养宠记.lnk`。
- 新快捷方式继续调用 Windows PowerShell，参数指向主项目中的 `启动单词消消养宠记.ps1`，工作目录为主项目目录。
- 描述统一为“启动单词消消养宠记”。
- 保持现有系统图标样式，本次只修正名称和目标，不额外设计图标素材。

### 分支交付

- 先在专用分支完成重命名、测试和整分支复审。
- 复审通过后，将 `codex/dog-pet-home-dialogue` 快进合并到主项目 `master`。
- 主项目现有未跟踪 `%SystemDrive%/` 目录保持原样，不暂存、不移动、不删除。
- 不推送远端。
- 合并后再切换桌面快捷方式，保证新快捷方式创建时目标脚本已经存在。

## 兼容边界

“彻底更名”指所有用户可见名称和启动入口。内部 `word-spirit-planet` 应用标识、`WORD_SPIRIT_*` 环境变量、令牌键和 API 路径继续保留，以保证旧账号、存档和现有接口兼容；这些内部标识不会展示给用户。

## 测试与验收

1. 先修改测试，使其要求新启动脚本存在、旧脚本不存在，并运行得到预期失败。
2. 重命名脚本和 README 后，运行启动器聚焦测试转绿。
3. 运行 `npm test`、`npm run check`、`git diff --check`。
4. 完成整分支只读审查，无阻断项后再合并主项目。
5. 合并后在主项目再次运行完整验证。
6. 创建新桌面快捷方式后读回属性，确认：
   - `单词消消养宠记.lnk` 存在；
   - `词灵星球.lnk` 不存在；
   - 参数指向主项目的 `启动单词消消养宠记.ps1`；
   - 工作目录为主项目；
   - 描述不含“词灵星球”。

## 错误处理与安全

- 若主项目无法安全快进、出现新的已跟踪修改或目标脚本被其它任务占用，停止交付并说明，不强行合并。
- 若桌面快捷方式无法创建，保留项目内已验证的新启动脚本并报告实际失败，不恢复旧名称。
- 删除快捷方式只针对精确路径 `C:\Users\86138\Desktop\词灵星球.lnk`；不扫描或删除其它桌面文件。
