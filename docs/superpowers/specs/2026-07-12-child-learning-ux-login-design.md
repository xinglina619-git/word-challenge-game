# 《词灵星球》小学生学习体验与登录可靠性优化设计

## 1. 目标

本轮优化把《词灵星球》从“有英语元素的消消乐”推进为“低年级儿童能够独立进入、理解玩法、获得明确学习反馈的英语陪练游戏”。保留现有词灵、美术、三消、配对、成长、免费抽卡和错词本，不新增付费、联网依赖或复杂家长后台。

成功标准：

1. 服务重启后，仍在有效期内的登录状态可以继续使用。
2. 忘记密码时，家长可在运行游戏的电脑上安全重置；局域网其他设备不能直接重置。
3. 音乐、游戏音效和单词朗读可分别开关，开关语义与实际播放行为一致。
4. 首次进入三消或配对关卡时，孩子不依赖成人说明也能完成第一步操作。
5. 三消通关同时考虑积分和本关不同词汇的学习覆盖，不允许只反复消除少数词通关。
6. 消除后的单词、中文、图示和再次朗读入口保持可见。
7. 390×844 手机视口下，核心按钮不重叠，昵称不换行，主要说明文字不小于 11px，棋盘单词尽量保持 11px。

## 2. 已确认问题与根因

### 2.1 登录可靠性

浏览器登录表单与 `/api/login` 已通过实际注册账号验证，基础校验链路可用。当前登录困难的主要原因是 `server.js` 使用内存 `Map` 保存会话，Node.js 服务重启后全部令牌立即失效；用户只能重新输入旧密码。界面又缺少密码显示、明确的恢复入口和提交状态，因此容易被理解为“登录功能坏了”。

### 2.2 声音控制

顶部音乐按钮只控制背景音乐。`tone`、`noise`、赞美声和单词朗读不受该按钮影响，关闭后仍会发声，违反用户预期，也不适合课堂或安静环境。

### 2.3 首次玩法理解

“自由寻找三连”没有解释“先点一个词块，再点相邻词块进行交换”。无效交换只显示短文本和震动，低年级儿童很难从反馈中推断正确操作。

### 2.4 学习闭环

现有三消只按积分通关，同一个熟悉单词可以反复贡献积分。中文释义会短暂弹出并进入顶部记忆栏，但没有再次朗读按钮，也没有明确展示“本关已接触多少个不同单词”。

### 2.5 手机端与首页层级

手机端棋盘整体可用，但顶部昵称可能换行，棋盘文字和部分说明低至 8～9px。首页把学习入口与抽卡、图鉴、商店并列展示，第一眼的主学习路径不够集中。

## 3. 方案比较与选择

### 3.1 登录

- 方案 A：继续使用内存会话，只改善错误文案。改动小，但服务重启后仍会退出，不解决根因。
- 方案 B：把原始令牌直接持久化到文件。能够跨重启，但令牌以明文保存，不必要地扩大泄露风险。
- 方案 C（采用）：客户端持有随机令牌，服务端只持久化令牌哈希、用户 ID 和到期时间；本机提供受限密码重置。兼顾家庭试玩的易用性与基本安全边界。

### 3.2 学习通关

- 方案 A：仅降低或提高积分目标。无法衡量词汇覆盖。
- 方案 B：要求每个词都消除固定次数。学习更严格，但随机三消下可能造成挫败。
- 方案 C（采用）：积分目标加“不同词汇覆盖目标”，通常为本关 5 个词中的 4 个；当积分已达标但覆盖不足时，提示系统优先指向尚未学习的词。学习有效性更高，同时保持可玩性。

### 3.3 声音设置

- 方案 A：一个总静音开关。操作最简单，但无法满足“保留单词朗读、关闭音乐”的学习场景。
- 方案 B（采用）：提供“背景音乐、游戏音效、单词朗读”三个独立开关，并保留一个清晰的声音设置入口。
- 方案 C：加入连续音量滑杆。控制最细，但对低龄用户和当前试玩版过于复杂。

## 4. 详细设计

### 4.1 持久会话与本机密码恢复

服务端新增会话存储文件 `data/sessions.json`。文件只保存 SHA-256 令牌哈希、`userId` 和 `expiresAt`，不保存浏览器收到的原始令牌。注册和登录创建 30 天会话；每次鉴权清理过期记录；退出登录删除对应哈希。旧的内存会话接口保持相同响应格式，前端无需迁移现有 token 字段。

新增 `POST /api/password/reset-local`：

- 仅接受来自 `127.0.0.1`、`::1` 或 IPv4 映射回环地址的请求。
- 输入手机号、新密码和确认密码。
- 成功后更新 `salt` 与 `passwordHash`，撤销该用户全部旧会话，并创建一个新会话直接返回。
- 非本机请求返回明确说明：“请在运行游戏的电脑上重置密码”。
- 不返回账号是否存在的差异化细节给非本机请求。

登录界面增加：

- 密码“显示/隐藏”按钮。
- 提交中的禁用状态与“正在进入……”文案。
- 登录失败错误显示在表单内部并自动聚焦，不只使用短暂 toast。
- “忘记密码？”入口；本机展示重置表单，局域网设备展示操作说明。
- `autocomplete="tel"`、`current-password`、`new-password` 等正确属性。

### 4.2 三轨声音设置

前端状态拆为：

```js
audio: {
  music: true,
  effects: true,
  speech: true
}
```

分别持久化到 `localStorage`。背景音乐调度只读取 `music`；`tone`、`noise` 和赞美提示音读取 `effects`；`speakWord`、`speakWords` 与赞美语音读取 `speech`。声音按钮改为有文字标签和 `aria-label` 的设置按钮，弹层提供三个大尺寸开关，并显示“建议保留单词朗读”。全部关闭时图标明确显示静音状态。

### 4.3 首次操作教学

进度数据增加：

```js
tutorials: {
  match3: false,
  pair: false
}
```

首次进入三消关：

1. 遮罩弱化非棋盘区域。
2. 从当前真实可行移动中选择一组相邻词块并高亮。
3. 文案分两步显示：“先点发光词块”与“再点旁边词块，交换成三个相同单词”。
4. 孩子完成一次有效交换或选择“我会了”后结束教学并保存，不消耗提示道具。

首次进入配对关：突出一组实际中英搭档，说明“先点一个，再找它的搭档”。教程不可阻塞返回按钮，并支持以后从声音设置旁的“玩法帮助”重新打开。

无效交换反馈改为“这两个相邻词块还不能组成三连”，短暂保留选中来源位置，并提供一次不消耗道具的可行移动闪烁，避免只有否定反馈。

### 4.4 词汇覆盖通关与提示

三消局内新增：

```js
learnedTypes: Set<number>
coverageGoal: number
```

`coverageGoal = Math.min(4, words.length)`。每次主动消除或连锁消除都记录对应词型。通关条件同时满足：

```text
score >= scoreGoal
learnedTypes.size >= coverageGoal
```

界面在积分旁显示“已学 2/4”。积分已达标但覆盖不足时，提示改为“还差 2 个新词”，免费高亮一次能够消除未学习词的移动；不存在该类移动时安全重排棋盘。配对关本身要求完成全部词，不额外改变通关规则。

覆盖只记录“本局真实消除过的不同词”，不把随机出现或查看算作掌握。永久错词与掌握逻辑沿用现有数据结构，避免本轮扩大数据库迁移范围。

### 4.5 常驻学习卡

顶部“本次学习词”区域保留最近一次学习结果，并显示：

- 英文单词。
- 中文释义。
- 高可信图示；抽象词不强行配图。
- “再听一次”按钮。

消除动画完成后学习卡仍保持，不因棋盘 settle 被清空。多个词同时消除时最多保留最近三个，并允许逐个点击朗读。弹出的中文卡继续作为即时奖励，但常驻卡承担复习功能。

### 4.6 首页与手机端信息层级

首页保持现有英雄区与“开始消除”为唯一主按钮。入口分组为：

- “继续学习”：选择关卡、错词本。
- “成长奖励”：免费抽卡、词灵图鉴、金币道具屋。

成长奖励在视觉上降低一级，不移除功能。首次玩家的提示卡固定显示“先完成第 1 关”，有历史进度后再轮播技巧。

手机端调整：

- 顶部昵称单行省略，不再换行。
- 主要说明文字最小 11px，按钮辅助文字最小 10px。
- 棋盘词块隐藏装饰性小星号，把空间留给至少 11px 的英文。
- 390×844 下棋盘、三个道具按钮和底部导航可连续滚动访问，不互相遮挡。
- 所有交互按钮保持至少 44px 的触控高度；尊重 `prefers-reduced-motion`，降低震动、爆炸和循环浮动动画。

## 5. 数据流与兼容性

### 登录

```text
登录表单 → /api/login → 校验密码 → 生成随机令牌
→ sessions.json 保存令牌哈希 → 浏览器保存原始令牌
→ /api/me 对令牌再次哈希并查找有效会话
```

现有 `data/users.json` 不迁移、不提交。首次启动缺少 `sessions.json` 时自动创建。旧 token 在升级后会失效一次，之后的登录状态可跨服务重启保持。

### 游戏学习

```text
有效交换 → 找到消除词型 → learnedTypes 更新
→ 朗读与常驻学习卡 → 同时检查积分和覆盖目标
→ 未达覆盖目标时优先提示未学词 → 达标后结算
```

旧账号缺少 `tutorials` 时自动补默认值；其他进度字段保持兼容。

## 6. 错误处理与安全边界

- 会话文件损坏时不覆盖用户数据；记录错误并回退为空会话，要求重新登录。
- 会话保存采用临时文件后重命名，避免写入中断留下半个 JSON。
- 密码重置仅允许本机请求，最少 6 位，并撤销旧会话。
- 登录、注册和重置表单都显示服务不可达、校验失败和账号错误，不吞掉异常。
- 声音 API 不可用时保留视觉反馈，设置界面标明该通道不可用。
- 动画执行期间维持现有 `busy` 锁，教程和学习卡不能触发重复结算。

## 7. 测试与验收

### 自动测试

扩展 `scripts/smoke_game.js` 与新增服务器测试脚本，覆盖：

- 会话保存的是令牌哈希而不是原始令牌。
- 服务模块重新加载后，同一 token 仍能通过 `/api/me`。
- 退出和密码重置后旧 token 失效。
- 非回环地址不能调用密码重置。
- 三个声音开关分别阻止对应播放通道。
- 三消只有积分和覆盖均达标才通关。
- 教程选择真实可行移动且不消耗道具。
- 学习卡包含图示、中文和再次朗读动作。
- 旧进度缺少新字段时可安全归一化。

### 浏览器验收

- 桌面端完成注册、退出、登录、服务重启后自动恢复、密码显示切换和本机重置。
- 首次三消教学能引导完成一组真实消除；第二次进入不重复弹出。
- 分别关闭音乐、音效和朗读，确认只有对应通道停止。
- 达到积分但未达到词汇覆盖时不提前结算；补足新词后正常通关。
- 390×844 手机视口检查登录、首页、教程、棋盘、学习卡和声音设置。
- 浏览器控制台无错误，`node --check`、自动测试和 HTTP 冒烟测试全部通过。

## 8. 不在本轮范围

- 短信验证码、云端账号、跨设备同步。
- 付费、广告和商业化抽卡。
- 完整家长后台或学习报表。
- 录音评分、语音识别和口语纠音。
- 重做全部关卡内容或替换现有美术资产。
