# 《词灵星球》桌面版真实登录与可靠启动交付设计

## 1. 目标与成功标准

本轮修复把桌面快捷方式交付链路从“可能打开任意占用 3000 端口的旧页面”改为“只打开身份已验证的《词灵星球》服务”，并把注册与登录拆成两个明确步骤。注册只创建家庭账号；用户随后必须使用刚才的手机号和密码显式登录，登录成功后才创建持久哈希会话并进入真实游戏首页。

成功标准：

1. 未登录且没有有效本地令牌时，默认显示登录页。
2. 登录、注册页签都是 `type="button"`，并通过 `aria-selected` 明确当前选中项。
3. 注册请求只创建用户，不创建会话，不返回 token；注册成功后自动回到登录页，保留手机号、清空密码并聚焦密码框。
4. 登录验证成功后才创建会话、保存 token，并进入游戏首页；服务重启后有效会话仍可恢复。
5. 提交期间显示准确的中文忙碌状态并禁止重复提交；错误和成功状态具有稳定、可聚焦、可自动化验证的语义。
6. `GET /api/health` 能唯一标识当前应用与版本。
7. 桌面启动器只使用端口 `31876`，只在健康响应匹配时复用服务，不杀死未知进程。
8. 最终从桌面快捷方式链路完成注册、回登录、登录、进入首页和服务重启恢复验收，浏览器控制台无错误。

## 3. 认证交互与数据流

### 3.1 默认入口与页签

`loadUser()` 在没有本地 token 时把视图设为 `login`。登录页和注册页共享认证卡片，但页签按钮显式使用 `type="button"`、`role="tab"`、`aria-selected="true|false"`，避免按钮被当成表单提交，也让当前状态能被辅助技术和自动测试稳定识别。

认证状态增加以下受控字段：

```js
auth: {
  busy: false,
  error: '',
  success: '',
  phone: '',
  passwordVisible: false
}
```

输入值由状态和表单提交共同维护。页签切换会清理不适用于新页面的错误或成功信息，但保留用户明确需要继续使用的手机号。

### 3.2 注册

注册提交过程：

```text
表单提交 → busy=true → 显示“正在注册…”并禁用提交
→ POST /api/register → 校验手机号、密码和档案
→ 写入 users.json → 返回 ok/message/phone
→ 不创建 session，不返回 token 或 user
→ 切换登录页 → 保留 phone → 清空密码
→ 显示成功状态 → 聚焦密码输入框
```

成功响应固定为：

```json
{
  "ok": true,
  "message": "注册成功，请使用刚才的手机号和密码登录",
  "phone": "已规范化的手机号"
}
```

响应不得包含 `token`。服务端测试还会直接检查 `sessions.json`，确认注册前后没有新增会话。

### 3.3 登录

登录提交过程：

```text
表单提交 → busy=true → 显示“正在登录…”并禁用提交
→ POST /api/login → 校验手机号和密码
→ 验证成功后创建持久哈希会话
→ 返回 token 和公开用户数据
→ 浏览器保存原始 token → 进入真实游戏首页
```

只有 `/api/login` 成功后才写入 `word_spirit_token`。注册成功、注册失败、登录失败都不能覆盖现有存储为无效 token。

### 3.4 状态与错误语义

- 表单错误使用 `role="alert"`、`tabindex="-1"`，重新渲染后自动聚焦。
- 注册成功提示使用 `role="status"`，文案固定为“注册成功，请使用刚才的手机号和密码登录”。
- 登录与注册提交按钮在 `busy` 时禁用；事件处理器在入口再次检查 `busy`，避免快速重复提交。
- 忙碌文案分别为“正在登录…”和“正在注册…”，不能沿用模糊的“正在进入”或“正在创建”。
- 网络失败、服务端校验错误和账号错误都在表单内持久显示，不依赖短暂 toast。

密码重置仍沿用既有本机接口：成功后撤销旧会话、创建新会话并进入首页。退出登录仍撤销当前会话并清除浏览器 token。

## 4. 健康接口与版本

新增无需认证的 `GET /api/health`：

```json
{
  "app": "word-spirit-planet",
  "version": "0.3.0",
  "ok": true
}
```

接口返回 `200`、JSON 和 `Cache-Control: no-store`。`package.json` 版本同步更新为 `0.3.0`，启动器同时校验三个字段，不能只依赖 HTTP 200 或端口监听。

## 5. 桌面启动器

`启动词灵星球.ps1` 固定使用：

```text
Host: 127.0.0.1
Port: 31876
Health: http://127.0.0.1:31876/api/health
App: word-spirit-planet
Version: 0.3.0
```

启动顺序：

1. 定位脚本所在项目目录，并确认 `node.exe` 可执行；缺失时显示中文错误并退出非零状态。
2. 请求健康接口。若响应完全匹配，则直接复用现有服务。
3. 若健康不匹配，再检查端口是否正在监听。若已被其他服务占用，显示中文错误，说明不会结束未知进程，并退出非零状态。
4. 若端口空闲，创建 `output/`，以隐藏窗口启动 `node server.js`，传入 `PORT=31876`，把标准输出和错误日志写入 `output/`。
5. 以短间隔轮询健康接口，最长 8 秒。完全匹配后才继续；超时则显示中文错误和日志位置并退出非零状态。
6. 成功后打开 `http://127.0.0.1:31876`。测试模式通过环境变量禁止自动打开浏览器，不改变生产默认行为。

启动器不结束、不覆盖、不接管任何未知进程。健康响应为其他应用、其他版本或无效 JSON 都视为不匹配；若此时端口已占用，必须停止并报错。

## 6. 缓存、文件与兼容性

- `index.html` 更新 `app.js` 与 `styles.css` 查询版本，确保桌面浏览器不会继续加载旧认证脚本或样式。
- 静态资源路径和现有游戏数据结构不迁移。
- `data/users.json` 和 `data/sessions.json` 均保持原位置；启动脚本不创建测试数据目录。
- 自动测试使用临时目录或 `output/qa-*` 隔离目录，完成后不写入真实数据文件。
- 日志只包含启动状态和错误，不输出请求体、手机号、密码、Authorization 头或原始 token。

## 7. 自动测试设计

### 7.1 认证与健康接口

扩展 `scripts/auth_flow_test.js`，使用随机空闲端口和独立临时数据目录覆盖：

1. `GET /api/health` 返回严格的应用标识、`0.3.0` 和 `ok=true`。
2. 注册返回 `ok/message/phone`，不返回 token 或 user，`sessions.json` 会话数不增加。
3. 注册后的 `/api/me` 在无令牌时返回 401。
4. 显式登录返回 token 和 user；服务重启后同一 token 仍可访问 `/api/me`。
5. 本机密码重置撤销旧 token 并返回新 token；旧密码不能登录，新密码可以登录。
6. 退出撤销当前 token。
7. 测试输出只显示行为标签，不显示测试手机号、密码或 token。

### 7.2 前端认证语义

扩展 `scripts/smoke_game.js`，对真实视图函数和提交状态模型覆盖：

1. 无 token 默认视图为登录。
2. 页签使用 `type="button"`、`role="tab"` 和正确 `aria-selected`。
3. 注册成功状态使用 `role="status"`，手机号保留，密码字段清空。
4. 登录与注册按钮在忙碌时禁用，并显示各自准确文案。
5. 错误状态使用 `role="alert"`、可聚焦且不依赖 toast。
6. 重复提交由状态入口和按钮禁用共同阻止。

### 7.3 启动器

新增可重复的 PowerShell 测试脚本，使用隔离端口、临时伪服务或测试环境变量覆盖：

1. 已有匹配健康服务时不重复启动 Node。
2. 空闲端口能启动服务并在 8 秒内通过健康校验。
3. 端口被健康不匹配的服务占用时返回中文错误，且未知进程仍存活。
4. Node 路径无效时返回中文错误。
5. 启动超时时返回中文错误并给出日志位置。
6. 测试模式不打开浏览器。

启动器测试不得操作 `31876` 上的真实桌面服务；测试端口通过参数或环境变量注入，生产默认值仍固定为 `31876`。

## 8. 浏览器与桌面交付验收

先在隔离端口和隔离数据目录执行真实浏览器验收：

1. 默认看到登录页。
2. 切换注册，提交时看到“正在注册…”。
3. 注册成功后回到登录页，显示成功状态，手机号保留，密码为空且密码框获得焦点。
4. 使用刚才的凭据登录，提交时看到“正在登录…”，成功后进入首页。
5. 停止并重启同一隔离服务，刷新后仍保持登录。
6. 控制台错误数为 0。

自动检查和隔离验收完成后，在保持真实 `data/` 不变的前提下，将任务分支快进到原目录 `master`。最后从桌面快捷方式 `词灵星球.lnk` 的真实链路启动，重复注册、回登录、显式登录、进入首页和服务重启恢复验收。桌面验收账号使用专门的测试账号，但不得在报告或日志中记录其完整手机号、密码或 token。
