# 三消仅保留中英文方块设计

## 背景与目标

当前三消会在英文、中文和图片三种展示面之间随机生成方块。试玩反馈认为图片会分散中英文对照训练，因此本次仅调整三消：棋盘只显示英文和中文，第二类中英配对游戏的“看图配词”继续保留。

## 范围

- 三消初始棋盘、补落、重排生成的方块展示面只能是 `en` 或 `zh`。
- 同一含义连续三个或以上时，必须同时包含至少一个英文方块和一个中文方块才可消除。
- 纯英文三连、纯中文三连均不可消除。
- 三消渲染不再输出图片方块；若旧状态中意外出现 `image` 展示面，按中文展示，避免重新出现图片。
- 删除仅服务于三消图片方块的无用样式和测试预期。
- 保留图片词典、图片选择逻辑和第二类配对游戏的图片词牌。

## 不在本次范围

- 不修改配对游戏的图片、星级、计分或错误次数规则。
- 不修改三消计分、步数、提示、重排、特殊消除、双语播报、鼓励词或背景音乐。
- 不调整词库内容和关卡顺序。

## 实现设计

### 方块生成

三消方块生成函数统一从 `['en', 'zh']` 中选择展示面。初始棋盘、消除后的补落以及重排都继续复用同一生成入口，从源头保证不再产生图片方块。

### 匹配规则

现有“英文 + 释义侧”判定保持结构不变。由于释义侧只剩中文，实际规则自然收敛为“英文 + 中文”。提示与死局检测仍按 `type + face` 区分交换，因此同一单词的英文和中文交换仍可形成有效走法。

### 渲染与兼容

三消渲染只输出文字节点：`en` 显示英文，其余展示面显示中文。这样即使页面热更新前残留了旧 `image` 数据，也会降级为中文。配对渲染继续独立调用图片选择逻辑，不受影响。

### 缓存与说明

更新前端脚本缓存版本，确保浏览器加载新逻辑；同步 README 中三消玩法说明。启动器的缓存版本断言随之更新。

## 测试设计

- 先增加失败测试，断言各三消关卡生成的方块只包含 `en`、`zh`。
- 覆盖初始棋盘、补落和重排共用的方块生成入口，不允许 `image` 回归。
- 验证英文与中文混合三连可消除，纯英文和纯中文不可消除。
- 验证三消 HTML 不含图片方块标记；旧 `image` 方块渲染为中文文字。
- 保留并执行配对图片映射与“看图配词”测试，证明第二类游戏未受影响。
- 运行完整自动测试、语法检查和 390×844 浏览器验收，确认棋盘仍为 6×6、无横向溢出、控制台无错误。

## 验收标准

1. 任意新开始或重排后的三消棋盘都只出现英文和中文。
2. 三消必须由同一含义的英文与中文混合组成三个以上方块才可消除。
3. 第二类配对游戏仍能显示图片词牌。
4. 既有音乐、语音、鼓励词、计分、星级和其他玩法保持不变。
5. 自动测试、语法检查和真实浏览器验收通过。
