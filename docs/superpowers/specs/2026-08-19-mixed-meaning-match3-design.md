# 三消词义混合与反馈优化设计

## 目标

本次调整让三消玩法从“识别相同英文”转为“建立英文与词义的对应关系”，同时简化消除后的界面反馈，并修复配对关星级长期固定为二星的问题。

## 用户体验

### 三消规则

- 每个棋盘格仍属于某一个具体词条，但展示面分为英文、中文、图片三种。
- 有明确图片的词条可出现英文、中文、图片三种展示；没有可靠图片的词条只出现英文和中文。
- 三个及以上同一词条连成横线或竖线后，只有同时包含以下两侧才算有效消除：
  - 至少一个英文方块；
  - 至少一个释义方块，释义方块可以是中文或图片。
- 纯英文组合、纯中文组合、纯图片组合以及只包含中文和图片的组合都不能消除。
- 四连、五连、交叉消除、级联、提示与重排继续沿用现有玩法，但只基于有效的中英混合组合计算。

示例：

- `apple + 苹果 + 🍎`：可以消除；
- `apple + apple + 🍎`：可以消除；
- `apple + apple + apple`：不能消除；
- `苹果 + 🍎 + 苹果`：不能消除。

### 棋盘视觉

- 三消棋盘的所有普通方块使用同一套柔和暖灰色背景，不再按词条或展示面使用不同底色。
- 棋盘容器使用略深的中性灰，方块使用较浅的灰白色；选中、提示、爆炸状态可保留高对比描边和动效。
- 英文和中文使用深色粗体并放大；图片在方块内居中放大。
- 手机窄屏下仍需完整显示六列，长单词允许自适应缩小，不能横向溢出。

### 顶部区域与消除反馈

- 删除游戏中的整块顶部学习卡，不再显示“本次学习词”、词义卡、再次朗读按钮或飞入顶部的动画。
- 关卡、得分、剩余步数等必要信息保留在紧凑的游戏头部；连击数据移入现有得分信息区。
- 有效消除时，方块完成爆破后直接消失并补充新方块，不再弹出或保留单词卡。
- 每次消除仍按顺序播报英文和中文；多个词条同时消除时逐组排队，避免互相打断。

### 背景音乐

- 将用户提供的 `草莓酱紫 - 倒计时BGM.mp3` 复制为项目内固定音频资源，并作为全局循环背景音乐。
- 删除按词灵切换合成主题曲的行为，所有词灵使用同一首新背景音乐。
- 音乐继续受现有“背景音乐”开关控制，并遵守浏览器必须由首次用户操作启动音频的限制。
- 游戏音效和单词朗读开关保持独立。

### 鼓励词

鼓励词统一为五级，并使用正确拼写：

1. `GOOD JOB`
2. `NICE`
3. `GREAT`
4. `EXCELLENT`
5. `UNBELIEVABLE`

普通三消使用较低等级；四连、连续消除、范围效果和五连逐级提高。删除 `AMAZING` 与 `BONUS TIME`，金币奖励仍可保留，但不再作为独立鼓励词。

### 配对关星级

- 配对关单独按失误次数评分，不再复用三消关的剩余步数阈值。
- 零失误完成：三星；
- 失误一至两次：二星；
- 失误三次及以上但完成关卡：一星。
- 三消关继续按剩余步数评分。

## 技术设计

### 棋盘数据

棋盘格从单一的词条编号调整为包含词条编号与展示面的对象：

```js
{ type: 0, face: 'en' }
{ type: 0, face: 'zh' }
{ type: 0, face: 'image' }
```

匹配检测分两步：先按 `type` 找出长度至少为三的连续线，再检查该线是否同时含有 `en` 与至少一个非 `en` 展示面。提示、可行移动、开局生成、重排与级联都调用同一个有效性判断，避免界面提示与真实消除规则不一致。

新方块生成时按词条能力选择展示面：有可靠图片映射时允许三种展示，没有图片时只允许英文和中文。开局棋盘不能自带有效消除，并且必须至少存在一个满足混合条件的可行移动。

### 音频

背景音乐改用一个可循环的 `HTMLAudioElement`。用户关闭背景音乐时暂停并保留当前位置，再次开启时从该位置继续；退出账号或页面重新加载后从头播放。朗读使用现有系统语音能力，为英文和中文分别创建带语言标记的语音项，并通过同一队列顺序播放。

### 评分

配对关新增明确的失误计数，每次错误配对加一。关卡结算通过独立评分函数按游戏模式返回星级，使三消和配对不再共享不适用的阈值。

## 错误与降级处理

- 浏览器无法播放 MP3 时，游戏仍可继续，声音面板保留关闭或重试入口，不回退到旧合成音乐。
- 系统缺少中文语音时继续播报英文，不能阻塞棋盘结算。
- 某词条没有可靠图片时使用中文作为释义侧，不能使用含义模糊的装饰图代替。
- 棋盘生成多次未找到有效移动时重新生成整盘，不能向用户提供无效提示。

## 验证范围

- 自动测试覆盖混合消除的正反例、四连和五连、可行移动、开局无自动消除、重排及补充方块。
- 自动测试覆盖五级鼓励词及配对关零失误、一至两次失误、三次以上失误的星级。
- 自动测试确认顶部学习卡和消除后记忆区不再渲染，并确认背景音乐资源路径与开关行为。
- 浏览器实测桌面和手机尺寸，检查六列棋盘、字体和图片可读性、无横向溢出、音频可开关、配对三星可获得。

## 不在本次范围内

- 不改变关卡数量、词库内容、账号存档、抽卡或道具系统。
- 不改变配对关的卡片布局和配对方式，除星级算法外不重做配对玩法。
- 不新增在线音乐来源或音频上传入口。
