# 词灵专属音乐与卡通配音设计

## 目标

将游戏音频拆成互不混用的三条逻辑声轨：

1. 每只词灵拥有自己的程序化背景主题，装备词灵时立即切换。
2. 教学单词使用清晰、偏童声的英语朗读声线。
3. GOOD、GREAT、EXCELLENT、AMAZING、UNBELIEVABLE、BONUS TIME 使用独立的卡通赞美声线与独立提示音。

## 方案选择

### 采用：离线程序化主题音乐

每只词灵配置独立节拍、旋律、低音、伴奏音色和循环长度，由 Web Audio API 实时演奏。优点是无需下载音乐、无版权风险、离线可用，并能在更换词灵时立即停止旧主题、启动新主题。

### 暂不采用：打包八首录音音乐

音质更接近正式游戏，但需要用户提供录音或购买可商用素材，并增加安装体积。当前结构会保留未来替换为 MP3/WAV 的入口。

### 不采用：联网音乐流

会破坏离线试玩能力，也带来网络、版权和儿童隐私方面的额外问题。

## 音乐主题

- 灵灵：明亮星光，轻快三角波。
- 星芽灵：森林萌芽，柔和木琴感。
- 泡泡灵：水滴跳跃，圆润正弦波。
- 糖果灵：糖果乐园，活泼短音。
- 火花灵：电光节拍，较强切分但控制音量。
- 云朵灵：轻盈云层，较慢、舒展。
- 月光灵：月夜摇篮，最柔和的节奏。
- 彩虹灵：彩虹庆典，明亮上行旋律。

主题随 `progress.equipped` 决定。切换伙伴时先清理旧主题已排程音符，再启动新主题，避免两首音乐叠加。

## 语音分工

### 教学发音

- 角色：`learning`
- 优先选择英语儿童、青年或轻柔声线。
- 语速约 0.82，音高约 1.32，以清晰为第一优先级。
- 连续消除多个单词时按顺序朗读。

### 赞美发音

- 角色：`praise`
- 必须调用与教学发音分开的选择器与播放函数。
- 有多套系统英语语音时，排除教学声线后选择另一套声音。
- 使用更高音高、更有惊喜感的语速，并为六个等级配置不同音高与提示音。
- 系统只有一个英语语音时，仍使用独立的卡通参数和提示音，保证听感与单词发音明显不同。

## 容错

- 浏览器没有 SpeechSynthesis 时，保留视觉赞美词和 Web Audio 提示音。
- 浏览器没有可用英语声线时，使用默认系统声线配合卡通参数。
- 自动播放受浏览器限制时，在第一次点击后启动音乐。
- 音乐关闭状态继续保存在 `word_spirit_music`，更换词灵不会强行打开音乐。

## 验证

- 自动测试验证八只词灵都有不同主题配置。
- 自动测试使用模拟声库验证教学声线和赞美声线不会选择同一个 voiceURI。
- 自动测试验证六个赞美词都有独立参数。
- 浏览器验证装备不同词灵后当前主题 ID 随之改变，且只有一个音乐循环计时器。
