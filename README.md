# 《词灵星球：英语单词消消乐》试玩版

一个面向小学英语学习的跨端三消游戏，可在电脑和手机浏览器中运行。

## 启动

双击 `启动词灵星球.ps1`，或运行：

```powershell
npm start
```

访问 `http://localhost:3000`。手机与电脑连接同一 Wi-Fi 后，可使用电脑局域网 IP 加端口 `:3000` 访问。

## 已实现

- 手机号与密码注册、账号存档和昵称编辑
- 自由积分三消与中英配对两类关卡自动交替，开局先显示玩法
- 6×6 三消棋盘，任意寻找三连；消除后自动朗读英文并弹出中文意思
- 达到本关累计目标积分即可通关，四连、五连及级联会获得更强特效和分数
- 消除释义卡延长展示后飞入顶部记忆栏，并保留到下一次消除
- 具象名词在中英配对中优先使用图片式图标，抽象词继续显示中文
- 分级英文赞美声：GOOD、GREAT、EXCELLENT、AMAZING、UNBELIEVABLE、BONUS TIME
- 分级粒子、火箭、彩虹、金币雨和连击音效
- 每5关星愿宝箱、每10关错词 Boss，连续五次正确触发金币爆发
- 一至五年级共 100 关分级词库：一年级110条、二年级120条、三年级308条、四年级照片词表、五年级316条
- 经验、金币、成长称号和免费抽卡券
- 7只独立原创词灵、幼年/成长/闪耀形态与伙伴选择
- 免费抽卡召唤动画、公开概率、十抽稀有与三十抽传说双保底
- 抽卡可获得词灵或增强道具；金币道具屋不包含付费内容
- 词灵图鉴、错词本、排行榜与响应式电脑/手机界面
- 轻快节奏的原创程序化背景音乐；不限制单次游玩时长

## 数据说明

账号数据保存在 `data/users.json`。旧版账号会自动迁移到新的进度结构。密码使用 Node.js `scrypt` 哈希存储。当前服务器适合家庭局域网试玩，不包含支付、短信验证和云端部署。正式上线预留项目见 `docs/上线功能预留.md`。

教材数据保存在 `textbook-words.generated.js`，运行时无需联网。一、二年级按广州出版社《英语口语》上下册衔接，三、五年级按教育科学出版社广州教科版上下册整理；四年级采用家长提供的教材照片词表。
