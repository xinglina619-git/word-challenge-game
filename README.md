# 《单词消消养宠记》试玩版

一个面向小学英语学习的跨端三消游戏，可在电脑和手机浏览器中运行。

## 启动

双击 `启动词灵星球.ps1` 后访问 `http://127.0.0.1:31876`。桌面启动器会先严格检查 `/api/health` 的应用名与 0.3.0 版本；端口被其他服务占用时会用中文说明原因，不会结束未知进程。

命令行开发方式仍可运行：

```powershell
npm start
```

默认访问 `http://localhost:3000`；也可先设置 `PORT` 环境变量使用其他端口。手机与电脑连接同一 Wi-Fi 后，可使用电脑局域网 IP 加对应端口访问。

未登录时默认显示登录页。新账号需要先切换到注册页；注册成功后请返回登录页（界面会自动切换并保留手机号），再使用刚才的手机号和密码显式登录。只有登录验证成功后才会创建持久会话并进入游戏首页。

## 已实现

- 手机号与密码注册、跨服务重启登录、本机密码恢复、账号存档和昵称编辑
- 自由积分三消与中英配对为主玩法，开局先显示玩法
- 6×6 中英文混合三消：同一词条必须同时出现英文与中文，三个以上才能消除
- 消除时依次朗读英文和中文，方块随后直接消失，不保留顶部学习卡
- 同时达到本关目标积分和不同词汇覆盖目标才可通关，四连、五连及级联会获得更强特效和分数
- 具象名词在中英配对中优先使用图片式图标，抽象词继续显示中文
- 分级英文赞美声：GOOD JOB、NICE、GREAT、EXCELLENT、UNBELIEVABLE
- 分级粒子、火箭、彩虹、金币雨和连击音效
- 每5关星愿宝箱、每10关错词 Boss，连续五次正确触发金币爆发
- 一至五年级共 100 关分级词库：一年级110条、二年级120条、三年级308条、四年级照片词表、五年级316条
- 每个账号可从六种小狗中免费领取一只并自主命名；旧账号可无损重选犬种，保留名字和全部养成、学习进度
- 小狗只在宠物屋出现，每日最多一次温柔提醒，三步引导完成“赚金币 → 换食物 → 回宠物屋喂食”
- 闯关获得的金币可兑换星星饼干、鲜果杯、营养套餐、庆典蛋糕和学习道具；喂食后会显示距下一级还差多少成长值
- Lv.2–Lv.10 共解锁九种纯展示特技；满级后不再喂食、不消耗食物，点击改为摸摸感谢
- 宠物不会饥饿、生病、退级；游戏不含充值、付费、随机抽取或能力加成
- 约8%的低频复习关会在主玩法之间出现，分配结果会保存且不会连续出现，只使用此前消除或配对成功的单词
- 拼写复习关每次连续2题：看中文、听英文并按顺序选择字母；同词首次错误会纠正并重试
- 单词落体关每次连续5题：在7/6/5秒内从三个中文释义中选择；首次玩法另有不计成败的引导题
- 经验、金币、成长称号、宠物之家、金币商店、错词本、排行榜与响应式电脑/手机界面
- 使用统一循环背景音乐；背景音乐、游戏音效和单词朗读可分别开关
- 中英配对按失误次数评定一至三星

## 数据说明

账号数据保存在 `data/users.json`，会话哈希保存在 `data/sessions.json`。旧版账号会自动迁移到新的进度结构。密码使用 Node.js `scrypt` 哈希存储，忘记密码时只能在运行游戏的电脑上重置。当前服务器适合家庭局域网试玩，不包含支付、短信验证和云端部署。正式上线预留项目见 `docs/上线功能预留.md`。

教材数据保存在 `textbook-words.generated.js`，运行时无需联网。一、二年级按广州出版社《英语口语》上下册衔接，三、五年级按教育科学出版社广州教科版上下册整理；四年级采用家长提供的教材照片词表。
